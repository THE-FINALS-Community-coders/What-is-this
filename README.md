# What-is-this
### A reference repo meant to hold definitions for things that may be confusing, misunderstood, or other. inside the TFCC!
----


So, you may ask when reading somthing, "what is this?" and have no info without looking it up!\
well thankfully in the TFCC, we implemented this system called the "what is this?" system!\
if we see somthing that may be confusing to a community member, there will be a "what is this? #partA" hyperlink, to the spot that it was related to! (hence the #part thing!)\
if there is somthing that needs a "what is this?" note, we will add a part to this repo! 

> [!NOTE]
> This repo is VERY NEW, so there will not be very much!
